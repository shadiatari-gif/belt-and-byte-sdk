# Contributing to Belt & Byte AI (Public SDK)

We welcome contributions from supply chain engineers, Python developers, and B2B integration specialists.

## Areas Open for Contribution
1. **Material & Engineering Schemas**: Extending `schemas/rfq_schema.json` with new industry standards (ASTM, DIN, ISO).
2. **Regional Connectors**: Building new adapters in `connectors/` for East Asian and G20 manufacturing hubs.
3. **Validation Utilities**: Improving local schema validation and error reporting.

## Submission Process
1. Fork the repository.
2. Create a feature branch (`git checkout -b feature/new-connector`).
3. Ensure all mock tests pass (`python examples/mock_agent.py`).
4. Submit a Pull Request to the `main` branch for maintainer review.
